# Dataset Information

This project uses two Reddit-derived datasets for binary Stress-versus-Depression text classification.

## Stress Dataset
Stress samples are obtained from the Dreaddit dataset. Only positively labelled stress samples are used.

## Depression Dataset
Depression samples are obtained from the Depression Reddit Cleaned Dataset. Only positively labelled depression samples are used.

## Final Dataset
After preprocessing, duplicate removal, and class balancing:

- Stress: 1,854 samples
- Depression: 1,854 samples
- Total: 3,708 samples

The original datasets are not redistributed in this repository. The repository contains information and code used for dataset preparation and experimental analysis.
